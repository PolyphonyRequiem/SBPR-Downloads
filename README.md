# SBPR playtest downloads

Unsigned, experimental Windows/Linux launcher and modpack downloads. These are not production releases.

Only downloadable artifacts live here; this repository does not publish the private development history. A Valheim licence and a legitimate Steam installation are required. Game binaries and player saves are never redistributed.

The initial 0.2.45 playtest package is approved for distribution, not for production deployment. Launcher-mediated join verification and Windows runtime verification remain outstanding. Server feed configuration is not yet available; do not substitute a local fixture address or arbitrary server.
